# Security

The currently maintained version is the latest release in this repository.
Pre-releases are for early testing and may have incomplete platform validation.

Please report security issues through this repository's **Security → Report a
vulnerability** if private reporting is enabled. Otherwise open an issue asking
for a private reporting channel, without publishing exploit details or secrets.
Do not include ADS tokens, browser cookies, credentials or private library data.

Zotero plugins run with access to platform internals and local files. Install
packages from the release page you trust. Cookie import is optional and initiated
by the user. No website should be treated as an instruction to run privileged
operations. Bundled third-party code and licenses are listed in
THIRD_PARTY_NOTICES.md.
