# 使用说明

## 浏览与搜索

主工具栏地球按钮控制右侧 dock 的展开和折叠。切换资料库条目不会重建浏览器，
折叠隐藏浏览器和分隔条，再展开保留标签。独立阅读器中的地球定位到主窗口 dock。
在主页搜索框输入关键词或网址，回车执行；标签栏可添加新标签、切换皮肤或打开设置。

先聚焦主页/网页，再使用 Command/Ctrl + plus（也支持 equals）、minus、0 缩放。
每次调整 10 个百分点，范围 50%–300%。PDF 缩放会退出适应宽度。

## Cite

在内置浏览器打开 arXiv 摘要/PDF，或在 Zotero 中打开对应论文，点击引用图标。
Cite 出现在内部小浮窗；打开 PDF 不会自动打开或查询。可手动输入 arXiv、DOI 或
ADS 文章链接。面板显示 ADS 原始 BibTeX，支持复制、自动复制、另存 `.bib`，或
保存为独立的 `Cite — 论文标题` 笔记。Esc 或 × 关闭。

主工具栏 Cite 优先识别 Zotero 当前阅读器，其次使用列表选中条目；浏览器内 Cite
使用浏览器当前来源。查找不确定、未收录或有多个匹配时不会猜测。

批量区域可选择选中条目、当前分类（可含子分类）或当前资料库，先检查范围，再
逐篇获取并保存。成功文章保存到所属资料库/分类，关联原文献。失败列表支持重试，
也可以停止。重复运行更新已有 Cite 笔记，保留用户文字；请保留自动标签。
批量任务目前不能跨重启恢复。额度限制时停止，稍后重试或配置个人 ADS Token。

个人 Token 存储在 Zotero/Gecko 登录管理器。已保存的 Cite 可离线查看。

## 生词与句子

启用 Translate for Zotero 后，在原生阅读器选中英文，翻译并点击“加入生词记录”。
每个 PDF 对应一条独立笔记，后续保存追加到该笔记，包含英文、中文、页码和回链。
相同中英对照不重复写入。生词和 Cite 使用不同标题与自动标签。

内置浏览器 PDF 可在设置启用划词翻译后保存，按来源 URL 记录；导入到资料库后的
附件标识与在线 URL 是不同来源。删除笔记后再次保存会新建；请保留自动标签。

## 分享本地 PDF

PDF 阅读器按钮顺序为复制 PDF、地球、Cite。点击复制按钮，将当前本地 PDF 文件
放入剪贴板，然后到支持文件粘贴的应用粘贴。文件未在本地会提示原因。主工具栏
不显示全局复制按钮。复制不移动或修改原 PDF；接收应用决定是否接受文件粘贴。

## 皮肤

点击调色盘或主页“自定义背景”。色卡显示真实底色、文字色和强调色，点击应用。
背景点击缩略图先预览，调整遮罩与位置后点击应用背景。✓ 表示当前背景，边框
表示当前预览。恢复当前撤销预览，关闭再打开也恢复已应用状态。

可导入 JPG/PNG/WebP（最大 20 MB）；验证后复制到 Zotero 数据目录，立即应用并
替换上一张导入图片。移除只删除插件副本。背景仅用于主页，搜索框保持浅底深字。

## 网站登录与保存

设置中的 Cookie 导入支持手动文本以及 macOS 浏览器检测；仅由用户主动发起。
它不能完整迁移站点登录状态。登录或人机验证遇到问题可转到外部浏览器。

arXiv 保存会尝试读取官方元数据并下载 PDF。其他网页目前只保存基础字段。
下载附件失败仍保留父条目并提示。重复点击保存可能创建重复条目。

如需反馈，请提供插件版本、Zotero 版本、系统与复现步骤，不要上传 Cookie、Token
或私人资料库。见仓库 Issues 和 PRIVACY.md。
